# Contributing to Techies @ VITM

Thank you for your interest in contributing to Techies @ VITM!

Techies @ VITM is a student community built around technology, learning, projects, opportunities, open source, and collaboration across VIT Mumbai.

We welcome contributions from students who want to improve the community and its resources.

## 🛠️ Ways You Can Contribute

You can contribute by:

* Adding useful learning resources
* Improving documentation
* Updating the club and community directory
* Sharing verified opportunities
* Improving project documentation
* Fixing errors or outdated information
* Suggesting new community initiatives
* Improving the repository itself

## 🚀 Contribution Workflow

### 1. Find an Issue

Look through the repository's open Issues and find something you would like to work on.

If an Issue does not exist, you can create one describing your idea or proposed improvement.

### 2. Discuss Before Major Changes

For larger changes, explain your idea in an Issue before starting significant work.

This helps avoid duplicated work and keeps contributions aligned with the community.

### 3. Create a Branch

Create a separate branch for your work.

Example:

```bash
git checkout -b docs/github-resources
```

Use a clear branch name related to your contribution.

### 4. Make Your Changes

Make your changes locally and keep them focused on the Issue you are working on.

### 5. Review Your Changes

Before committing, check what changed:

```bash
git status
```

Review your files and make sure there are no accidental changes.

### 6. Commit

Use a clear commit message.

Example:

```bash
git add .
git commit -m "docs: add beginner GitHub resources"
```

### 7. Push Your Branch

```bash
git push -u origin docs/github-resources
```

### 8. Open a Pull Request

Open a Pull Request from your branch to the main branch.

Explain:

* What you changed
* Why you changed it
* Which Issue it addresses

### 9. Review

Maintainers may request changes or ask questions.

Please respond to review feedback constructively.

### 10. Merge

Once the contribution has been reviewed and approved, a maintainer can merge the Pull Request.

## 📌 Contribution Guidelines

Please make sure your contribution is:

* Relevant to Techies @ VITM
* Accurate and useful
* Respectful and constructive
* Clearly written
* Original or appropriately attributed
* Free from sensitive personal information

Do not submit copyrighted material without permission.

## 🌱 Beginners Are Welcome

You do not need to be an open-source expert to contribute.

If you are making your first contribution, start with documentation, resource updates, typo fixes, or other beginner-friendly Issues.

If you are unsure about something, open an Issue or ask the community.

## 🤝 Community Standards

All contributors are expected to follow the project's Code of Conduct and the Techies @ VITM community rules.

Thank you for helping make Techies @ VITM better.

**Learn. Build. Collaborate.**
